# Basic Concepts


### What is Object-Oriented Programming (OOP)

- Everything is treated as an **object**.

### There are two types of OOPs

##### Pure
- Everything is treated as an **object** here.  
- It does not support **primitive data types**.  
- **Example**: **Smalltalk**. It is the only programming language which supports **pure OOPs**.

##### True
- It supports **primitive data types**.  
- **Example**: **C++**, **Java**, **Dot Net** (.NET)


## What are the features of OOPs?

- Features of OOPs are – **class**, **object**, **encapsulation**, **data hiding**, **data abstraction**, **inheritance**, **polymorphism**, **abstraction**.  
- But the main **four pillars** are – **encapsulation**, **inheritance**, **polymorphism**, **abstraction**.


## Class

- It is a **logical entity**.  
- It contains information of their members like:  
  - **member variable**  
  - **member method**  
  - **static variable**  
  - **static method**  
  - **constructor**  
  - **destructor**  
  - **access modifier**  
  - **constant pool**



## Object

- It is a **physical entity**.  
- It is a collection of **member variables** stored into **heap area** at runtime.



## Constructor

- It is used to **initialize members** of an object.



## New

- It is a **functional operator**.  
- `new` is responsible to **initialize an object**.



## Destructor

- It is used to **deinitialize members of** an object.



## Delete

- It is a **functional operator**.  
- `delete` is responsible for **deinitialization** of an object.



## Data Hiding

- **Outside person can't access our data directly.**



## Data Abstraction

- To **highlight the set of services** by hiding its **internal implementation details**.  
- We achieve it using **private access modifier**.



## Encapsulation

- The combination of **data hiding** and **data abstraction** is called **encapsulation**.
- To encapsulate **members of a class** into single unit is called **encapsulation**.



## Inheritance

- When **public** and **protected** members of a class directly accessible into another class is called **inheritance**.



## Polymorphism

- When an **object** have **symbolic reference** of any **method** is called **polymorphism**.



## Abstraction

- **Hiding internal implementation details** of a class is called **abstraction**.
